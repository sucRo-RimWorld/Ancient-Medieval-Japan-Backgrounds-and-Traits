# P3 focused background gap / prior-art decision — 2026-10-19

## Narrow player outcome and counted baseline
Original Ludeon Core 1.6/1.7 has 784 BackstoryDefs and 43 TraitDefs in the Project's original Core metadata audit. Characters main currently restricts **135 distinct** ordinary background identifiers (adult 77 = 76 category restrictions + FerventResearcher72; childhood 58 = 55 named Solid gates + 3 Shuffled restrictions); it rewrites **123 different** existing background IDs (34 earlier + 89 approved) without overlap with the 135 restricted IDs. Thus 526 original DefNames are neither restricted nor rewritten; this arithmetic does **not** guarantee that any particular pawn/faction may roll them. Existing 123 reworks already include farmers, soldiers, tradespeople, craftsmen, healers and temples: duplicating those labels is not a reason to add Defs.

**Scoped gap:** The accepted 123 Japanese titles contain no specific working **near-shore fish processing/net craft** or **collective irrigation maintenance** background. Generic seafarers, farmer backgrounds, and tradespeople remain present. Add a *small* four-background P3 slice: a shore-raised child / working shore fish handler and a paddy-water childhood / adult irrigation caretaker. These give civilian manual skill histories not reliant on a fishing subsystem or the AMJ Waterworks Mod. Do not pretend the Vanilla Animals skill is fishing. The four defs add no required equipment, auto Trait, job, cultivation or water mechanic. The colony's selected biome need not match every backstory: a historical origin is not a current tile guarantee.

## Decision: minimal independent Characters addition, not wholesale replacement
Existing Vanilla/MO and already rewritten 123 histories remain the default variety. Independent four original content IDs are justified **only** as the missing Japan-framed, low-status coastal and shared-water rural biographies with ordinary cross-skill combinations. Do not import European/HAR/VE package content and hide most of it to simulate Japan. Use own authored prose and unchanged 1.6/1.7 BackstoryDef format; tags `Tribal` and `Civil` for base generation and `Medieval`/`MedievalCommon` for players using category-adjusting medieval patches. No edits to other Mod faction filters or pre-existing 784 IDs. The exact natural appearance rates are engine/faction-dependent and not verified here. Four extra eligible entries add modest variety; balance choices avoid forced Traits, permanent work disable, or starting possessions. English and Japanese Def texts live only in Characters.

**Explicit deferred decisions:** No exact quota of 135 replacements is mandated. Proposed P3 traits such as 義理堅い / 職人気質 have no author-approved distinct effect or proven nonduplication against Kind, Industriousness and related originals; do not add empty traits merely to restore a count. Their future design/approval is separate from this bounded four-background slice. Old-save/new-save compatibility and original 1.7 loaded appearance are untested. No Steam release.
