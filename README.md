# AMJ Culture – Characters（中世日本 - 文化・人物）

Independent Mod for ancient-to-medieval Japanese character backgrounds and traits, split **only** from [AMJ Culture](https://github.com/sucRo-RimWorld/Ancient-Medieval-Japan-Culture).

**Status: separated into current Culture main (`52b16d398112a64b6f934dc0f5ea2ee0cc77c9e8`). Independent DLLs built; scoped original RimWorld Vanilla 1.6 Characters-alone, 1.6 paired and 1.7 paired game tests all PASS. Avoid older unsplit Culture builds. Development Mod, not Steam-published.**

- Original BackstoryDef/TraitDef identities, skills and work restrictions preserved.
- 77 adult and 58 childhood restrictions; 34 earlier + 89 author-approved historical rewrites; 23 starting-possession replacements; Transhumanist and DrugDesire ordinary-generation suppression, plus alcohol-only likes/dislikes traits with modest mood effects while intoxicated.
- Approved English XML and Japanese DefInjected, separate Solid-child Harmony patch and `AMJ.Culture.Characters` source project.
- Harmony required, Medieval Overhaul optional; no mandatory Culture dependency.
- Greedy/Jealous shared-lodging mood rules, initial chemical addictions, other drugs, entrances, meals and bedding stay in Culture.
- New game recommended; old-save compatibility not guaranteed.

[Design](Docs/Design.md) is authoritative; [Coordination](Docs/Coordination.md) tracks cutover. Unsplit Culture historical native evidence is not transferred retroactively.
