# AMJ Culture – Characters（中世日本 - 文化・人物）

Independent Mod for ancient-to-medieval Japanese character backgrounds and traits, split **only** from [AMJ Culture](https://github.com/sucRo-RimWorld/Ancient-Medieval-Japan-Culture).

**Status: Characters source and independent 1.6/1.7 binaries built. Characters-alone original 1.6 native PASS; paired Culture runtime cutover NOT accepted. Do not install alongside unsplit Culture main or publish yet.**

- Original BackstoryDef/TraitDef identities, skills and work restrictions preserved.
- 77 adult and 58 childhood restrictions; 34 earlier + 89 author-approved historical rewrites; 23 starting-possession replacements; Transhumanist ordinary generation suppression.
- Approved English XML and Japanese DefInjected, separate Solid-child Harmony patch and `AMJ.Culture.Characters` source project.
- Harmony required, Medieval Overhaul optional; no mandatory Culture dependency.
- Greedy/Jealous shared-lodging mood rules, initial chemical addictions, other drugs, entrances, meals and bedding stay in Culture.
- New game recommended; old-save compatibility not guaranteed.

[Design](Docs/Design.md) is authoritative; [Coordination](Docs/Coordination.md) tracks cutover. Old Culture native acceptance belongs to *unsplit* Culture. Extracted Characters alone passed scoped original 1.6 loaded-game tests (Project [run #39228255901](https://github.com/sucRo-RimWorld/Ancient-Medieval-Japan-Project/actions/runs/39228255901)); paired original 1.6 still failed with native Mono GC crash and remains unresolved. Independent 1.7 Characters DLL is built but native acceptance is not yet verified.
